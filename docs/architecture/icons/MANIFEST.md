# Icon provenance

Regenerate with `docs/architecture/extract-nvidia-icons.py <deck>`.

The NVIDIA icons are NVIDIA brand assets, lifted from NVIDIA's own
architecture-diagram iconography deck for GTC Berlin 2026. The source deck
is not committed; the extractor takes its path as an argument. The three
lockups come from this repository's own UI assets and keep their own colours.
